# 农药毒性分级与使用限制

## 毒性分级标准

中国农药毒性分为五级，依据大白鼠经口 LD50 值划分：

| 毒性级别 | 经口 LD50 (mg/kg) | 标识颜色 | 风险等级 |
|---------|-------------------|---------|---------|
| 剧毒 | ≤ 5 | 红色 | 极高 |
| 高毒 | 5 - 50 | 红色 | 高 |
| 中等毒 | 50 - 500 | 红色 | 中等 |
| 低毒 | 500 - 5000 | 黄色 | 低 |
| 微毒 | > 5000 | 蓝色 | 极低 |

## 高毒农药使用限制

根据农业农村部公告，以下高毒农药受到严格限制或已禁用：

### 已禁止使用的农药（部分）

- 甲胺磷、对硫磷、甲基对硫磷、久效磷、磷胺（五种高毒有机磷）
- 毒鼠强、氟乙酰胺、甘氟
- 六六六、滴滴涕（有机氯类）

### 限制使用的高毒农药

- **甲拌磷**：仅限种子处理，禁止叶面喷雾和土壤撒施
- **克百威**：仅限颗粒剂土壤处理，禁止喷雾
- **涕灭威**：仅限棉花拌种，禁止在食用作物上使用
- **氧乐果**：禁止在蔬菜、瓜果、茶叶上使用
- **水胺硫磷**：禁止在蔬菜、柑橘等食用作物上使用
- **毒死蜱**：部分省份已禁止在蔬菜上使用

### 安全操作要求

高毒农药使用时必须遵守：
- 佩戴防护手套、口罩和防护服
- 施药区域设置警示标志
- 施药后 24 小时内禁止人畜进入
- 不得在水源地附近施药
- 不得与碱性物质混用

## 中等毒农药注意事项

中等毒农药（如高效氯氟氰菊酯、氯氰菊酯、毒死蜱等）使用时需注意：
- 避免在蜂场附近施药（对蜜蜂有毒）
- 鱼塘周边谨慎使用（对水生生物有毒）
- 蔬菜和果树收获前严格遵守安全间隔期
- 不要随意加大用药浓度

## 低毒农药推荐优先级

农业生产中应优先选择低毒农药：
- **新烟碱类**：吡虫啉、啶虫脒、噻虫嗪、呋虫胺 — 高效低毒，适用范围广
- **双酰胺类**：氯虫苯甲酰胺、氟苯虫酰胺 — 对鳞翅目高效
- **抗生素类**：阿维菌素、甲维盐、多杀霉素 — 生物源农药，环境友好
- **生物农药**：枯草芽孢杆菌、井冈霉素、春雷霉素 — 微生物源，残留极低

## 合规检查要点

合规推理链中 toxicity_risk 检查的逻辑：
1. 剧毒农药：任何食用作物上都应 blocked
2. 高毒农药：蔬菜、果树、茶叶上应 blocked，粮食作物上 warning
3. 中等毒农药：检查是否为限用品种及使用场景
4. 低毒/微毒：一般 passed，但仍需检查安全间隔期
