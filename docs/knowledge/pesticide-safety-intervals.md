# 农药安全间隔期参考表

## 什么是安全间隔期

安全间隔期（PHI，Pre-harvest Interval）是指最后一次施药到作物收获之间的最短间隔天数。在此期间农药残留自然降解到安全水平以下。安全间隔期因农药种类、剂型、作物类型和施药浓度而异。

## 高毒农药特别提醒

以下高毒农药已禁止在蔬菜、果树、茶叶和中草药上使用，安全间隔期不适用：
- 甲拌磷：仅限种子处理，禁止叶面喷雾
- 克百威：仅限土壤处理，禁止喷雾
- 涕灭威：禁止在食用作物上使用
- 氧乐果：禁止在蔬菜上使用
- 水胺硫磷：禁止在蔬菜和果树上使用

## 施药次数限制

- 同一生长季内，同类农药施药次数不宜超过 3 次
- 应交替使用不同作用机制的农药，延缓抗药性
- 收获前 30 天内应减少施药频次，优先选择生物农药
