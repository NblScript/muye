## 如何添加新设计文档

1. 在 `docs/design-docs/` 目录创建 `.md` 文件
2. 使用以下模板头部：

```markdown
# <标题>

> 一句话描述

## 状态
- [ ] 草稿
- [ ] 评审中
- [x] 已批准

## 最后更新
YYYY-MM-DD
```

3. 在本文件的"文档列表"表格中添加条目
4. 提交到 Git 仓库
