# 昆虫热力图产品规格

> 规定牧野首页昆虫热力图的产品范围、数据语义、展示边界和后续演进顺序。

## 状态

- [x] 已批准
- 最后更新：2026-08-04

## 产品目标

首页围绕一块实际业务田地回答四个问题：哪里发现了昆虫、相对热度多高、数据来自哪里、系统据此安排了什么作业。热力图必须能追溯到后端检测或明确标记的演示种子，不能仅作为循环动画或随机装饰。

## 当前范围

- 当前只展示一个活动田地。田地可使用项目内的虚拟边界，不接入省级行政地图。
- 当前输入是单张或一批巡检图片的 YOLO 检测结果，尚未接入实时视频流。
- 当前热值用于单次任务内的相对热点比较，不代表每亩虫口数或经济防治阈值。
- 当前图像到田地的投影是工程近似，不具有测绘级定位精度。
- 多田地切换、行政区聚合和云端地块管理不属于当前迭代。

## 当前数据契约

| 环节 | 当前规则 |
|---|---|
| 检测输入 | `pest_type`、`confidence`、`position` |
| 像素框 | `coordinate_space=image_pixel`，必须携带正数 `image_width`、`image_height` |
| 归一化框 | `coordinate_space=image_normalized`，坐标范围为 0–1 |
| 网格 | 默认 8 行 × 10 列 |
| 累计方式 | 检测框中心落入网格后累计置信度权重 |
| 归一化 | 所有网格除以本次任务的最大网格权重，得到 0–1 相对热值 |
| 投影 | `image_frame_to_geofence_bbox`，图像顶部映射田地北侧 |
| 来源标记 | `density_metadata.source`、`is_simulated`、接收/拒绝框数量 |
| 无有效检测 | 不制造热点；规划链路可降级为均匀喷洒 |

`density_grid[].density` 的正式名称是“相对热值”。页面可以使用低、中、高三个视觉分档，但不得把分档直接表述为农业生产中的轻度、中度、重度虫害等级。

## 变量喷洒规则

当前喷洒规则基于每条航线对应网格行的最大相对热值：

| 相对热值 | 喷洒倍率 |
|---|---|
| `>= 0.6` | 基础速率 × 1.5 |
| `>= 0.3` 且 `< 0.6` | 基础速率 × 1.0 |
| `< 0.3` | 基础速率 × 0.5 |

最终速率仍受 `spray_rate_range_lpm` 安全范围约束。这是项目内的变量喷洒调度规则，不替代当地植保规范、农药标签或农艺师处方。

## 前端展示要求

- 三维场景只展示项目内单块虚拟田地、热力层、检测点、航线和无人机状态。
- 热力数据优先读取 `latest_task.drone.instruction.density_grid`。
- 页面必须显示真实检测或模拟种子来源，不得将模拟数据标记为 YOLO 实测。
- WebSocket 空包、回退包和畸形包不能清除最后一帧有效热力数据。
- 同一份热力数据保持常量，不使用 `Math.random()`、定时扰动或逐帧随机重算。
- 没有有效任务时展示空状态，不使用虚假默认虫点填满田地。
- 1920×1080 与 1366×768 下，来源、图例、主要统计和任务状态必须完整可见。

## 下一阶段产品化需求

### P0：巡检与热力快照（数据层与查询 API 已完成）

- 为每次巡检保存田地、采集时间、图片、检测项、热力网格和来源元数据。
- 热力快照与 `request_id`、喷洒任务和复检任务建立稳定关联。
- 对旧任务缺失字段提供兼容读取，不在前端补造业务数据。

当前已完成 SQLite 持久化、喷洒前/复检关联、算法版本、旧任务只读转换，以及最新、筛选列表、详情和前后配对 HTTP API；前端已完成首页虫种子集热力、历史筛选、指标趋势和喷洒前后静态对比，待多分辨率浏览器视觉验收。

### P1：筛选与历史趋势

- 支持按昆虫种类和时间范围查询热力快照。
- 首页显示当前快照，历史页展示热点面积、峰值相对热值和检测数量趋势。
- 不同时间快照必须分别保留各自的归一化元数据，避免把相对值误作绝对同比。

### P2：喷洒前后对比

- 将喷洒前巡检、喷洒任务和喷洒后复检组成一个可追溯闭环。
- 对比检测数量、热点网格数量和同一昆虫类别的相对分布变化。
- 杀灭率与效果结论使用后端评估结果，前端只负责解释和展示。

## 暂不承诺

- 在没有正射影像或相机位姿时，不承诺虫点的绝对 GPS 精度。
- 在没有标准化采样面积和农艺标定时，不承诺绝对虫口密度。
- 在没有当地法规与农艺师复核时，不将相对热值直接作为自动施药依据。
- 在没有真实硬件验收时，不将动画无人机描述为真机执行结果。
