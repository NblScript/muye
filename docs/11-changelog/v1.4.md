# v1.4

发布日期：2026-04-17

本版本聚焦三件事：把前端主线切换到 React 指挥大屏、让 SQLite 决策增强链路以可插拔方式接入主线、以及稳定 PX4 可视化演示流程，便于后续现场演示与数据导入扩展。

## 核心更新

- SQLite 决策增强上下文已接入主线，但默认保持可控关闭。
- 新增 `modules/decision_context.py`，并在 `modules/ai_decision.py` 中支持按开关注入 SQLite 农业上下文。
- `modules/sqlite_store.py` 扩展了农业数据、历史天气、候选农药和决策支撑查询能力，为后续正式数据导入预留了稳定入口。

- 前端已完成从旧 Streamlit 方案向 `Vite + React + TypeScript` 的主线迁移。
- `frontend/` 现在是唯一前端实现，后端 `main.py -> api_app` 已补齐工作流、历史、上传、图片查看等接口。
- 演示脚本 `scripts/start_demo.sh`、`scripts/start_px4_visual_demo.sh`、`scripts/start_showtime.sh` 已统一切到 React 前端链路。

- PX4 可视化演示链进一步稳定。
- `modules/px4_simulator.py` 现在按真实遥测位置反算航线进度，前端地图已切换为纯 `SVG` 渲染，避免运行态地图容器导致的不可见问题。
- `config/drone_config.json` 已更新冬小麦演示地块、演示航线和相关超时参数。

- 新增部署与展示辅助能力。
- 增加 `deploy/nginx.conf`、`deploy/muye_backend.service` 与一键展示脚本，便于现场演示和后续部署落地。

## 工程状态

- 后端测试通过：`69 passed`
- 前端生产构建通过：`npm run build`

## 升级提示

- 当前版本已经为后续农业数据正式导入后的数据库参与决策预留了接入位，但默认不会强制启用数据库增强上下文。
- 如需启用 SQLite 决策增强链路，请显式配置 `MUYE_ENABLE_SQLITE_DECISION_CONTEXT=true`。
